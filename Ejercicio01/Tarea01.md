# Ejercicio 01 — Aplicaciones de IA que uso o he usado

## Objetivo

Identificar, en tu vida cotidiana o académica, sistemas que emplean inteligencia artificial y describir **cómo** los has utilizado.

## Indicaciones

Elabora una **lista de tres aplicaciones** de inteligencia artificial que uses o hayas usado.

Para cada una indica:

1. **Nombre de la aplicación** (por ejemplo: ChatGPT, Gemini, Copilot, traductor automático, recomendaciones de una plataforma, filtros de fotografía, asistente de voz, etc.).
2. **Cómo la usaste**: en qué contexto, para qué tarea y qué tipo de resultado obtuviste.

## Formato sugerido

1. **Nombre:**  read.ai
   **Uso:** Para traducción y notas de reuniones en teams. Todos los días en el trabajo durante las mañanas se lleva a cabo una reunión llamada Daily. Esta app fue de gran ayuda para traducir las reuniones, cuando estas eran en inglés. Y tener un resumen con los puntos de interés y pendientes por elaborar. Es una app muy útil. 

2. **Nombre:**  codex cli
   **Uso:** El principal uso que le doy es para generar código mediante especificaciones de código bien definidas. Previo un análisis ‘humano’ de requisitos y estado del código del proyecto se elabora un prompt y por medio del modo plan se genera una plan en formato md que posteriormente es refinado de acuerdo a juicio de ingeniera de software y luego de ser validado, el agente se encarga de ejecutar el plan, para posteriormente generar el código que es analizado y validado para su aprobación usando git hub pull requests.

3. **Nombre:**  gemini
   **Uso:** Para dar seguimiento a mis avances en concreto en mis rutina nutricional. Elaboro un archivo con información con mi peso del día, el consumo de agua, calidad de sueño, la cantidad de comida y ejercicio durante el día, para al final hacer un balance de cuánta ingesta de proteína o grasas fueron consumidas de esa manera mejorar la alimentación, de acuerdo a las recomendaciones de Gemini 

## Criterios

- Deben ser **tres** aplicaciones distintas.
- El nombre de cada app debe ser explícito.
- La explicación del uso debe ser concreta (no basta con escribir «la uso para todo»).
