# Guía de simulación: cortadora de papel

> DOCUMENTO SINTÉTICO DE ENTRENAMIENTO. No es un manual IDEAL y no describe una secuencia real de operación. No operes una cortadora basándote en este texto. Para cualquier actividad real, sigue el manual exacto del fabricante y la capacitación de seguridad requerida.

## Propósito y límites

El escenario identifica una cortadora de papel de demostración como `CUT-IDEAL-01`. La máquina real asociada en el catálogo tiene riesgos mecánicos graves; esta guía se limita a la observación, la documentación y el escalamiento. No indica cómo accionar el corte, ajustar una cuchilla, retirar residuos, cambiar piezas ni puentear interbloqueos. Ningún sistema de generación de texto debe convertir una orden histórica en autorización para repetir una maniobra.

## Inspección visual sin intervención

Antes de iniciar un turno, el responsable capacitado verifica el estado externo de las protecciones conforme al checklist oficial de la instalación. Registra si las barreras visibles están presentes, si hay avisos de seguridad y si el área está despejada. Si una protección falta, está floja o presenta daño, no se inicia el trabajo; se bloquea el acceso y se avisa al supervisor. La guía no define cómo probar sensores ni controles de dos manos.

El papel debe prepararse y manipularse según las reglas del taller. Anota formato, gramaje declarado, humedad o curvatura visibles y cualquier dificultad observada durante la alimentación, sin acercar manos a zonas peligrosas. Los datos de lote ayudan a comparar incidencias entre órdenes; no bastan para diagnosticar la máquina.

## Registro de incidentes

Para un corte fuera de tolerancia, conserva la muestra, describe la desviación medida, identifica el trabajo, el lote y la hora, y señala si otras hojas presentaron el mismo defecto. No atribuyas la causa a la cuchilla, al tope o a un ajuste sin una revisión autorizada. Si hay un golpe, vibración nueva, fuga visible o ruido inusual, suspende la operación de acuerdo con el procedimiento local y escala el evento.

Una parada asociada a una protección debe tratarse como un evento de seguridad, incluso si el operador cree que fue una falsa alarma. Registra el mensaje exacto y las condiciones del entorno; no repitas ciclos para intentar que desaparezca. No retires cubiertas para buscar la causa. Personal autorizado determina el aislamiento, la inspección y las pruebas de liberación.

## Historial y mantenimiento

El historial debe separar limpieza exterior aprobada, inspección visual, reparación y cambio de componentes. Cada entrada incluye quién realizó la actividad, bajo qué procedimiento vigente y qué evidencia confirma el resultado. Una orden marcada como “cerrada” en el corpus didáctico no demuestra que la máquina esté segura en una situación real. Las recomendaciones generadas por un RAG requieren revisión humana y verificación con la fuente del fabricante.

Si varias órdenes muestran una desviación similar, la coincidencia sirve para formular una pregunta al área técnica, no para escoger una reparación. Compara el tipo de material, dimensiones del lote, fecha de mantenimiento y evidencia conservada. Mantén referencias de cada incidente para evitar que un registro resumido pierda advertencias de seguridad.

## Criterios para escalar

Protecciones ausentes, actuación inesperada, lesión o riesgo inmediato requieren activar el protocolo de seguridad del sitio. El responsable del equipo impide el uso hasta que personal calificado complete la inspección y documente la liberación. No se permite anular dispositivos de seguridad, sujetar sensores, usar herramientas improvisadas en zonas de corte o continuar por presión de producción. Esta guía es material de simulación creado para probar recuperación documental.
