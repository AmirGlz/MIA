# Guía de simulación: impresora de producción

> DOCUMENTO SINTÉTICO DE ENTRENAMIENTO. No es un manual HP ni corresponde a un modelo comercial. No uses sus instrucciones para intervenir una máquina real; consulta el manual del fabricante y personal autorizado.

## Alcance y registro

Este documento describe un escenario didáctico de una impresora electrofotográfica de producción identificada como `PRN-HP-01` en las órdenes ficticias del corpus. Su objetivo es permitir consultas de demostración sobre síntomas, mantenimiento preventivo y trazabilidad. No especifica voltajes, temperaturas, secuencias de servicio ni códigos de error reales. Registra todo síntoma con fecha, contador mostrado por el equipo, tipo de sustrato, trabajo que se estaba procesando y mensaje literal del panel. No deduzcas la causa únicamente por una mancha aislada: conserva una muestra impresa y compárala con páginas posteriores.

## Rutina preventiva de entrenamiento

Antes del turno, el operador puede revisar visualmente que el área esté limpia, que las bandejas no estén obstruidas y que el papel corresponda al formato configurado. Comprueba en el panel si existen avisos de consumibles o atascos pendientes. Para cualquier limpieza, sustitución o apertura de una cubierta, sigue exclusivamente el procedimiento del fabricante. No toques componentes internos ni retires protecciones. Mantén los registros de reemplazo de consumibles asociados al equipo y al trabajo para distinguir desgaste recurrente de un incidente puntual.

Al cerrar el turno, registra atascos repetidos, variaciones de calidad y pausas inesperadas. Una misma falla reportada por trabajos diferentes puede sugerir revisar el proceso con soporte técnico, pero no demuestra por sí sola una pieza defectuosa. Conserva el original del reporte y evita editar retroactivamente los datos del incidente; agrega una nota de corrección con fecha y responsable si una entrada requiere aclaración.

## Síntomas y triage

Si aparecen líneas, manchas o zonas con densidad irregular, identifica si el defecto se repite en la misma posición en varias hojas y guarda ejemplos. Si solo ocurre con un lote de papel, registra proveedor, lote y condiciones de almacenamiento para comparar. Si el defecto persiste con otro trabajo, escala el caso a mantenimiento autorizado. Si aparece un atasco, anota bandeja, ruta indicada por el panel y frecuencia. No tires del papel en una dirección no indicada ni fuerces rodillos o puertas.

Cuando la salida pierde conectividad, registra hora, estación de trabajo, cola, estado que presenta el panel y si otras estaciones observan el mismo comportamiento. Separa problemas de envío del trabajo de problemas físicos de impresión. No borres trabajos pendientes ni reinicies la configuración de red sin autorización; conserva el mensaje de error para soporte.

## Evidencia para diagnóstico

Un informe útil contiene identificador del activo, síntoma literal, frecuencia, condiciones de aparición, muestra de salida, acciones no invasivas autorizadas y resultado posterior. Distingue observaciones de hipótesis: “la franja aparece en cuatro páginas” es una observación; “el fusor está dañado” es una hipótesis que requiere diagnóstico técnico. Las órdenes sintéticas relacionadas con esta guía pueden mostrar recurrencia en limpieza, alimentación o calidad, pero no constituyen una instrucción del fabricante.

## Escalamiento

Detén el uso y solicita asistencia cuando haya olor anormal, humo, ruido mecánico nuevo, una protección dañada o cualquier mensaje que el fabricante clasifique como crítico. Informa si el equipo continúa energizado y mantén despejada el área. Solo personal calificado decide aislamiento, reparación o liberación del equipo. El registro de mantenimiento debe cerrar con una prueba documentada y la identidad del responsable autorizado.
